🚀 如何启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  注意: Electron 二进制文件因网络证书问题未自动下载

方法 1: 手动下载 Electron (推荐)
────────────────────────────────────────────────────────
  1. 访问国内镜像下载:
     https://npmmirror.com/mirrors/electron/28.0.0/electron-v28.0.0-win32-x64.zip

  2. 解压到项目根目录（创建 electron-bin 文件夹）

  3. 运行:
     electron-bin\electron.exe src\main.js

方法 2: 全局安装 Electron
────────────────────────────────────────────────────────
  npm install -g electron
  electron src\main.js

方法 3: 配置 API Key (可选)
────────────────────────────────────────────────────────
  copy .env.example .env
  # 编辑 .env，填入 ANTHROPIC_API_KEY

  注: 没有 API Key 也能使用，会使用基础故事模板
