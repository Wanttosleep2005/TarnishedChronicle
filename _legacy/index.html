🎮 艾尔登法环褪色者编年史

✅ 项目已完成

一个用 Electron + AI 构建的存档解析工具，讲述每个玩家的独特史诗故事。

✨ 核心功能

📊 存档解析

解析二进制 .sl2 文件，提取角色、Boss、赐福、任务、区域数据

🧠 行为分析

识别战斗风格、探索模式、坚持度量、独特玩法

🏆 智能徽章

10+ 种独特徽章：翻滚大师、弹反之神、宁姆格福传说等

🤖 AI 故事

Claude AI 将数据转化为温暖叙事，失败重塑为英雄旅程

🎨 设计亮点

遵循温暖大地色调设计系统：

奶油色背景 #F7F4EF 陶土色强调 #C4612F Playfair Display 衬线 Inter 人文无衬线 毛玻璃导航 药丸按钮

🏆 独特徽章示例

  • 🌀 翻滚大师：连续翻滚 1000+ 次的闪避艺术家
  • ⚔️ 弹反之神：成功弹反 100+ 次的剑术宗师
  • ⚡ 宁姆格福传说：在初始区域刷到满级（"十里坡剑神"）
  • 💥 玻璃大炮：低生命值击败多个 Boss 的极限挑战者
  • 🗺️ 交界地探险家：解锁 80%+ 赐福点的探索狂人

🚀 启动方式

⚠️ 注意：由于网络证书问题，Electron 二进制文件未能自动下载。请手动下载或使用以下方法。

方法 1：手动下载 Electron

# 从国内镜像下载
https://npmmirror.com/mirrors/electron/28.0.0/electron-v28.0.0-win32-x64.zip

# 解压后运行
electron.exe src\main.js

方法 2：使用全局 Electron

npm install -g electron
electron src\main.js

方法 3：配置 API Key（可选）

# 复制环境变量模板
copy .env.example .env

# 编辑 .env，填入你的 Anthropic API Key
ANTHROPIC_API_KEY=your_key_here
