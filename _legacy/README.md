# 艾尔登法环 · 褪色者编年史

一个用 Electron 构建的艾尔登法环存档解析工具，通过 AI 讲述每个玩家的独特故事。

## 功能特性

### 🎮 存档解析
- 解析艾尔登法环存档文件（.sl2 / .co2）
- 提取角色信息、等级、游戏时长
- 分析 Boss 击败记录、赐福点解锁、区域探索
- 追踪任务完成情况和 NPC 互动

### 📊 行为分析
- **战斗风格识别**：翻滚次数、弹反次数、法术使用、跳跃攻击
- **探索模式**：区域停留时间、赐福点解锁率
- **坚持度量**：死亡次数、每 Boss 平均死亡数
- **特殊行为检测**：如"十里坡剑神"（低级区域长时间刷级）

### 🏆 成就徽章系统

自动颁发基于玩家行为的独特徽章：

- **翻滚大师** 🌀：连续翻滚 1000+ 次
- **弹反之神** ⚔️：成功弹反 100+ 次
- **不屈的褪色者** 💀：死亡 500+ 次仍未放弃
- **交界地探险家** 🗺️：解锁 80%+ 赐福点
- **超级药罐子** 🍶：过度依赖圣杯瓶
- **玻璃大炮** 💥：低生命值击败多个 Boss
- **宁姆格福传说** ⚡：在初始区域刷到满级（传说级）

### 🤖 AI 故事生成

使用 Claude AI 将游戏数据转化为富有感染力的叙事：
- 3-4 句话的个人史诗摘要
- 3-5 个关键时刻描述
- 将失败和挣扎重塑为英雄旅程的一部分
- 从玩家行为中挖掘独特闪光点

### 🎨 精美界面

- 温暖的大地色调设计（奶油色背景、陶土色强调）
- 衬线标题 + 人文无衬线正文
- 毛玻璃导航栏
- 响应式卡片布局
- 流畅的动画过渡

## 技术栈

- **Electron**：桌面应用框架
- **Node.js**：后端逻辑
- **Anthropic Claude API**：AI 故事生成
- **原生 JavaScript**：前端交互
- **CSS3**：现代化界面设计

## 安装使用

### 前置要求
- Node.js 16+
- Anthropic API Key（用于 AI 故事生成）

### 安装步骤

```bash
# 安装依赖
npm install

# 设置 API Key（可选，无 API Key 也能使用基础功能）
# Windows
set ANTHROPIC_API_KEY=your_api_key_here

# macOS/Linux
export ANTHROPIC_API_KEY=your_api_key_here

# 启动应用
npm start

# 开发模式（带调试工具）
npm run dev
```

### 使用流程

1. 点击"选择存档文件"按钮
2. 选择你的艾尔登法环存档文件
   - Windows: `%APPDATA%\EldenRing\<Steam_ID>\ER0000.sl2`
   - Steam Deck: `~/.local/share/Steam/steamapps/compatdata/1245620/pfx/drive_c/users/steamuser/AppData/Roaming/EldenRing/`
3. 等待解析和 AI 生成（约 5-10 秒）
4. 浏览你的独特故事、徽章和数据

## 存档格式说明

艾尔登法环存档文件（.sl2）是二进制格式，包含：

- **角色数据**：名称、等级、属性点分配
- **进度标志**：Boss 击败、赐福解锁、区域发现
- **统计数据**：游戏时长、死亡次数、物品使用
- **行为数据**：战斗动作计数、区域停留时间

本工具通过偏移量读取关键数据字段。实际存档格式更复杂，包含加密和校验和。

## AI 集成

使用 Anthropic Claude API 进行故事生成：

- **模型**：claude-sonnet-4-6
- **Prompt Caching**：减少重复系统提示的成本
- **Fallback 机制**：API 失败时使用本地生成的基础故事
- **隐私保护**：存档数据不会被存储，仅用于实时生成

## 注意事项

⚠️ **存档安全**：本工具仅读取存档，不会修改任何数据。但建议操作前备份存档文件。

⚠️ **存档格式**：当前解析逻辑是基于逆向工程的简化版本，可能无法完全准确解析所有数据字段。

⚠️ **API 成本**：每次生成故事会调用 Claude API，注意 API 使用额度。
